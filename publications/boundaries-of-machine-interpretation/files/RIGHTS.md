## Repository scope

This package-specific statement is intended to control these publication files
if they are mirrored into a repository with a broader default license. The
current `advanced-global-intelligence` repository describes text content as
MIT-licensed. A GitHub mirror must therefore add an explicit root-level
exception pointing to this file; copying the package into that repository
without the exception would leave the public licensing signal ambiguous.

For the Zenodo form, use a custom rights entry:

- Title: `No license granted — all rights reserved`
- URL: leave empty
- Description: `Copyright © 2026 Ivan Kotov. No license is granted by this record. Reuse is permitted only where authorized by applicable law or by separate written permission from the rights holder. Citation and linking do not imply permission to reproduce or adapt the files.`

Do not accept Zenodo's default CC BY 4.0 selection unless the author makes a
separate explicit licensing decision and all package metadata is revised.
