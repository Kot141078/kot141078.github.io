## Supersession rules

- `supersedes` changes which formulation is current; it does not erase the
  superseded object.
- `hasPart` does not make all parts the same semantic type.
- a publication version may include statement units with older versions when
  those units remain byte-identical.
- no site redirect, repository index, PDF, or metadata record may overwrite an
  older versioned artifact.
