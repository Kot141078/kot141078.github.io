C-Governed CLI Agent Mesh

Abstract

Executable worker governance

C-Governed CLI Agent Mesh v0.1.1 is a draft technical protocol package for governing executable CLI/cloud agents under persistent c governance, including synchronized Markdown sources, review PDFs, P0 JSON Schemas, semantic validator bindings, and synthetic fixture manifests.

The package is designed as a reviewable governance surface for bounded agent work, claim control, witness-compatible records, memory gates, and fail-closed execution boundaries.
