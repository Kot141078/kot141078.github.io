Summary

Memory and continuity layer

The CCDP AMDR/PAMDC Addendum v0.1.1 extends the Child-c Development Protocol corpus with a bounded memory and continuity layer. It introduces technical profiles for active memory degradation, memory recalibration, lifestream ingestion discipline, Judge integration, write-path failure detection, post-anchor memory degradation, and post-anchor continuity handling.

This is an addendum-only delta. It does not replace the CCDP v0.1 Full Technical Corpus or the CCDP v0.1.1 Hygiene Addendum.
