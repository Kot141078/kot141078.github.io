DOI-backed software / open verification release

Cleanroom ARM-P: Open Verification Release v1.0.1

A signed and reproducible publication surface for a bounded Python fixture-plane reference implementation covering deterministic evidence export, schema-governed validation, tamper-evident custody, SQLite transaction and recovery controls, and fail-closed state transitions.

Zenodo DOI GitHub repository GitHub Release v1.0.1 Signed source tag Browse all 27 documents

In plain language

One reviewable surface for evidence-heavy software

Evidence-heavy software is difficult to review when code, schemas, claims, fixtures, receipts, test results, and audit records are scattered across unrelated locations. This release binds those surfaces into signed and hashed packages so a reviewer can inspect the exact source, reproduce the bounded fixture workflow, and verify the published artifacts.

Boundary: this is not an autonomous AI system and not a production runtime. It is a bounded reference implementation and an open verification release.

What was built

Bounded implementation and evidence surfaces

  • Deterministic B1 evidence export and a tamper-evident custody chain.
  • A synthetic B2 fixture plane for bounded, reproducible validation.
  • Schema-governed records and machine-readable indexes.
  • SQLite transaction, failpoint, rollback, and recovery controls.
  • Signed Git history and a signed immutable release tag.
  • Deterministic fixtures and a package-local reproduction path.
  • Windows ZIP portability and complete checksum surfaces.
  • Human-readable documents paired with machine-readable navigation.

  • Real L4 capability.
  • Matched profile-control.
  • Differential witness.
  • A complete operational ARM-P runtime.

Checkout the signed release source

git clone https://github.com/Kot141078/cleanroom-arm-p-open-verification.git
cd cleanroom-arm-p-open-verification
git verify-tag v1.0.1
git checkout v1.0.1

Why Zenodo and GitHub both exist

Archive, source, mirror, and navigation

  • Zenodo is the canonical DOI archive.
  • The GitHub tag is the signed immutable source snapshot.
  • The GitHub Release mirrors the same 21 Zenodo files.
  • Repository main exposes individual documents and machine indexes for ordinary reading.
  • This site is an explanation and navigation layer, not a replacement archive.
