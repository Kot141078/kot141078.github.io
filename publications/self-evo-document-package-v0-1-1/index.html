Summary

Bounded self-evolution governance corpus

The Self-Evo Document Package v0.1.1 is a draft document-level governance corpus for bounded self-evolution of c = a + b systems. It integrates CGAM, SRLM, TRIAD-SYNAPS, Memory Gate, EA-L4, Anti-Autarky, Resource Actor Grounding, Local Checker rules, synthetic conformance fixtures, contradiction tracking, and open-issue tracking.
