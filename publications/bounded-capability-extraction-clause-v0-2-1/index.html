Summary

Capability extraction boundary

BCEC v0.2.1 is a final textual clause and b-layer PASS reviewed draft for extraction metering, source-class discipline, and anti-distillation handling in c-class capability extraction from external oracles.

Bridge map

Related control surfaces

  • A6 Composition Layer: anchor composition must not pool extraction.
  • Synthetic Laundering: egress source-class hands off to re-admission origin-class.
  • EA Value: extracted capability posture maps to value / contamination classes.
  • ARQ: extraction budgeting uses chain-rule and boundedness proof shape.
  • L4 Witness: extraction witness packets and hashable boundary records are required.
  • ARL / Conflict Class: extraction breach, reconstructive aggregate, and hidden participant routes lead to freeze, hold, quarantine, and appeal.
  • Beacon: Beacon remains upstream recognition and gate discipline; BCEC does not redefine Beacon classes.
  • CGAM / CLI Agent Mesh: relevant where external oracle calls are made by local/cloud agents, Judge assistants, or release workers; agents are workers, not authority.
