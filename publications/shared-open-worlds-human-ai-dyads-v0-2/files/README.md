# Shared Open Worlds for Human–AI Dyads: Role Switching, Experience Qualification, and Cross-World Continuity Evaluation

**Ivan Kotov · Version 0.2 · English publication edition · 6 September 2026**

A conceptual and methodological research preprint. This is the English edition of the author-accepted Russian v0.2; it reports **no new empirical results** and has not undergone separate independent peer review.

## Reading the package

Start with `A_C_SHARED_OPEN_WORLD_EXPERIENCE_PAPER_v0_2_EN.pdf`. The corresponding `.md` and `.docx` contain the text source and editable edition. In the PDF/DOCX, long source addresses use compact clickable labels; the full addresses remain in the link targets and Markdown.

`EDITION_AND_SOURCE_NOTE.md` records translation scope and the publication-only updates. `PUBLIC_SOURCE_SCOPE.json` carries the selectively exported source-coverage declarations of the Russian revision; it is not a new verification campaign. `CITATION.bib` supplies a citation without an invented DOI. `LICENSE.md` identifies CC BY 4.0 and its scope. `SHA256SUMS.txt` covers every other file in the package.

## Scientific boundary

The twenty main sections, H1–H4, controls B0/C/B1/B2, sixteen case families, and five author-constructed illustrations I01–I05 are retained. C is a candidate implementation of requirements, not a distinct mechanism or proved class. No separate C/B1 causal comparison is proposed until a genuine operational difference is specified. Correct permission handling, useful learning, and human enjoyment remain different outcomes.

The illustrations are not an independently annotated benchmark. No new game integration, model experiment, human study, or runtime implementation accompanies this paper. The research objective remains shared gameplay: enjoyment for the human and useful learning for the system, under separately testable boundaries.
