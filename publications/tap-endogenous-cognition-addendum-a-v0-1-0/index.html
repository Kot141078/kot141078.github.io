TAP v1.0 — Interpretive Addendum A

Endogenous cognition and the c-class boundary. An independent supplement to Temporal AI Presence Profile v1.0.

DOI 10.5281/zenodo.24265163 Read PDF Read Markdown GitHub source and checksums

The distinction

What the original TAP profile leaves implicit

Temporal AI Presence (TAP) describes AI participation that persists across tasks and sessions. A persistent assistant, a local AI node or a system using multiple agents may qualify as a temporal presence without thereby qualifying as c.

In TAP v1.0, sections 6.6 and 9.2 summarize the stricter c = a + b architecture in terms of an accountable human ANCHOR, technological substrate, continuity, L4 consequences, memory governance, witness, authority limits and challengeability. Section 13 governs background processing for TAP systems in general. Those abbreviated lists do not explicitly identify self-directed cognition as a necessary condition for an active c-line.

The omission matters for an implementer. A capable task agent can run scheduled searches, store a history and obey resource policies. Those mechanisms alone do not explain whether it has developed questions that remain meaningful and revisable within its own continuing trajectory. The addendum states this distinction while preserving TAP v1.0 section 4.2, which defers to the parent corpus, and section 20, which requires separate c-class conformance evidence.

Proposed criterion

Endogenous inquiry, not perpetual task execution

The note proposes endogenous, self-directed cognitive activity as a necessary but insufficient property for assessing an active c-line. Such a line must be capable of forming questions, assigning bounded attention to them, returning to unresolved matters, weighing alternatives and revising or ending its own directions after new evidence and consequences.

Consider a system that searches for publications every evening because a timer tells it to do so. Its database grows, but the repeated searches establish only scheduled work. Now consider a continuing research line that detects a conflict between an earlier accepted explanation and a new observation, keeps that conflict unresolved, checks it again when relevant evidence appears, and changes future priorities as a result. The question may have been triggered by external material; its subsequent integration and revision are the relevant observations.

This is a functional and developmental research criterion, not a declaration of machine free will or consciousness. A scheduler, RAG search, language model or temporary agent can be part of the substrate b. No single component is automatically the continuing line that uses it.

Formation

Installing a substrate does not install a biography

The addendum distinguishes a prepared technical substrate, an anchored formation candidate, observed self-directed development and conformance supported by the applicable evidence. A newly launched system need not already possess a mature vocation or a fully formed motivational history. Personality Formation v0.1 and MOT-c already describe how capabilities, experience, reflection, motives and maturity must be assessed separately.

The term active is deliberate. Own thought is not equivalent to constant clock-time computation. Quiet modes, sleep, interruption and cold wake have separate continuity and transition questions. A paused system must not be pronounced a different entity merely because its processor has stopped, but successful restart is not automatic proof of same-c identity.

Class and evidence

Names do not determine class membership

An independently developed system can be assessed against the same c-class criteria even if it is built from ordinary models, databases and agent tools, or marketed under a different name. The software itself remains part of b; the candidate object is the line formed through its relationship with the ANCHOR and the world. Calling something c is no substitute for the relevant evidence, and calling it an agent cannot by itself disqualify it.

Testing one condition by removing it from an otherwise matched configuration is useful for determining that condition's contribution. Other controlled comparisons can legitimately involve two candidate systems or two qualifying lines. Results must state precisely whether they measure memory recovery, task success, autonomous cognitive integration, authority conformance or a formation-path effect; those are distinct claims.

No experiment in this note establishes a c-specific causal effect against a maximal conventional baseline. No published results certify consciousness, personhood or lawful same-c succession. Endogenous cognition does not confer permission to spend money, alter protected memories or act beyond L4 and authority constraints.
