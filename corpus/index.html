Principle

Core principle

No claim, state, role, authority, continuity status, memory status, operational outcome, or validation status may be promoted to a stronger class without admissible evidence, explicit transition conditions, and a witnessable record.

This page translates that rule into a reader-facing map. It is not a new protocol family and it does not raise any source status.
