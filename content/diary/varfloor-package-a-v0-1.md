A new VARFLOOR publication package is now available:

VARFLOOR Package A v0.1
Theory, Methodology, and Appendix Ledger for Variety Floor Monitoring

DOI: [https://zenodo.org/records/21125117](https://zenodo.org/records/21125117)
Publication page: [https://ivankotov.eu/publications/varfloor-package-a-v0-1/](https://ivankotov.eu/publications/varfloor-package-a-v0-1/)

This package contains the public Package A theory/methodology family for VARFLOOR, including:

- 18 public PDFs
- 18 Markdown source companions
- manifests and checksums
- selected publication-audit reports
- source-intake reference metadata
- non-claim boundaries

The purpose of VARFLOOR is narrow:

to monitor when a system collapses below a usable variety floor.

It is not a judge, not an authority, not a conformance claim, and not a live-system readiness claim.

The package focuses on collapse fixtures, local checker methodology, pseudo-validator planning, skeleton handoff lineage, anchor and post-anchor boundary material, Article 50 transparency-support material, and appendix/gate-ledger traceability.

The publication is released under CC BY 4.0.

As usual, the important part is not the announcement.

The important part is that the archive is inspectable:

DOI, public page, Markdown companions, manifests, checksums, GitHub bridge, and explicit non-claim boundaries.
