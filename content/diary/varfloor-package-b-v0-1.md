A new VARFLOOR software package is now available:

VARFLOOR Package B v0.1
Pure Validator External Bench Software Package

DOI: [https://zenodo.org/records/21137756](https://zenodo.org/records/21137756)
Publication page: [https://ivankotov.eu/publications/varfloor-package-b-v0-1/](https://ivankotov.eu/publications/varfloor-package-b-v0-1/)

This package contains the public software archive for the VARFLOOR Pure Validator External Bench package.

It includes:

- frozen pure-validator external-bench software
- unpacked software-freeze copy for inspection
- Package B source-intake archive as provenance material
- 2 accepted academic PDFs
- 2 public Markdown companions
- selected audit reports
- manifests and checksums
- explicit license and non-claim boundaries

License split:

- code/software surfaces: AGPL-3.0-only
- documentation, reports, metadata, manifests, and explanatory materials: CC-BY-4.0

The package is intentionally narrow.

It is not a conformance claim.
It is not a live-c readiness claim.
It is not a Tomara integration claim.
It does not include a runtime adapter.
It does not claim deployment approval.

The point is reproducible external-bench evidence with traceable boundaries, not inflated certification language.

Package A covered the theory and methodology layer.
Package B publishes the software evidence box.
